Chess Career Mode — Lite

ติดตั้ง Node.js แล้วเปิด Terminal ในโฟลเดอร์นี้:
  npm ci
  npm run dev

สร้างไฟล์สำหรับนำขึ้นเว็บ:
  npm run build

ไฟล์ ZIP นี้เป็นซอร์สเกม ตัดเอกสาร ภาพ Playtest รายงาน ชุดทดสอบ และ dist ที่ซ้ำกับซอร์สออกแล้ว
ยังเก็บข้อมูลเมือง เสียง ภาพ เอนจิน และใบอนุญาตที่เกมต้องใช้ไว้
